## 带宽：固定带宽还是按流量，先算一笔账

判断标准很简单：带宽利用率长期低于10%，选按使用流量；利用率高、流量稳定，选按固定带宽。以北京地域为例，1M固定带宽23元/月，按流量计费1GB出流量0.8元。

这笔账可以自己算。1M带宽的下载速度是128KB/秒，满速跑满一个月大约有300GB上下的出流量，按0.8元/GB算就是250元左右的账单；而23元对应的流量约29GB，只相当于满载流量的9%左右。两边成本在这个点附近打平，这就是利用率10%这条分界线的算法依据。

带宽大小可以保守选。网站接上CDN加速、静态资源放对象存储OSS之后，源站带宽压力会小很多，个人网站1M基本够用。真不够用也不用慌，带宽支持在后台单独变配升级，CPU、内存和存储同样可以弹性升降配。
